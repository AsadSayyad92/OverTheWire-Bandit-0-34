# OverTheWire Bandit (Levels 0–34)

## 📌 About This Repository

This repository contains my **personal solutions and walkthroughs** for the **OverTheWire Bandit wargame**, completed using **Linux terminal (Kali Linux)**.

Bandit is designed to teach:

* Linux fundamentals
* File permissions
* SSH usage
* Text processing
* Basic scripting
* Privilege escalation concepts

I solved all levels **from Bandit Level 0 to Level 34** step by step.

---

## 🧠 What is OverTheWire Bandit?

Bandit is a beginner-friendly wargame focused on **Linux command-line skills** and **basic cybersecurity concepts**.

Each level requires:

* Reading files with special names
* Finding hidden files
* Understanding permissions
* Using tools like `grep`, `find`, `cat`, `strings`, `base64`, `tar`, `ssh`, etc.
